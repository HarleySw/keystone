# Installing Keystone for OpenCode

## Prerequisites

- [OpenCode.ai](https://opencode.ai) installed

## Installation

### OpenCode V1

```json
{
  "plugin": ["keystone@git+https://github.com/HarleySw/keystone.git"]
}
```

### OpenCode V2 (2.0.4 or later)

```json
{
  "plugins": ["keystone@git+https://github.com/HarleySw/keystone.git"]
}
```

Restart OpenCode. Verify by asking: `"Tell me about your Keystone skills"`

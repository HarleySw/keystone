# Claude Code Tool Notes

Claude Code is the reference harness: skills speak its vocabulary (`Agent` for subagent dispatch, `TodoWrite` for todos, `Skill` for invoking skills, `Read`, `Write`, `Edit`, `Bash`, `Grep`, `Glob`).

## Orchestration Note

When your human partner requests lower-cost coordination on multi-task plans, you may dispatch an orchestrator subagent on a mid-tier model while preserving all Keystone Visual Comprehension tables and Cognitive Verification Gates in the final summary relayed to the engineer.

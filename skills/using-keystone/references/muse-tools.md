# Muse Tool Mapping

| Action skills request | Muse equivalent |
| :--- | :--- |
| Read / Write / Edit a file | `read_file`, `write_file`, `edit_file` |
| Run a shell command | `bash` |
| Search file contents / Glob | `search` |
| Invoke a skill | `read_file` on `skills/<name>/SKILL.md` or native skill tool |
| Dispatch a subagent | `subagent_spawn` |
| Task tracking | `write_todos` |
| Ask the user a question | `request_user_input` |

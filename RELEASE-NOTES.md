# Release Notes

## v0.1.0 (2026-10-24)

### Initial Release — The Human-in-Command Agent Skills Ecosystem

Keystone `v0.1.0` establishes the foundational multi-harness architecture and core skills designed to eliminate **Comprehension Debt** while shipping at AI speed.

#### Highlights
- **Visual Comprehension Core (`using-keystone`)**: Enforces dry-run status tables (`✅` / `⚠️` / `❌`) and compact ASCII diagrams (`<76` chars) across all architectural and implementation workflows.
- **Cognitive Verification Gates**: Keeps the engineer in command with structured mental-model checkpoints before and after complex changes.
- **Hybrid Language Strategy**: Imperative English skill source (`MUST`, `NEVER`, zero zombie nouns) for optimal semantic routing and ~25% token savings, paired with natural domain-accurate user output (with strict anti-machine-translation rules for Vietnamese).
- **Meta-Skill (`writing-skills`)**: Complete TDD-adapted guide for authoring, pressure-testing, and packaging new Keystone skills.
- **Full Multi-Harness Support**: Out-of-the-box manifests and `SessionStart` bootstrap hooks for Antigravity (`agy`), Claude Code, Cursor, Codex, Gemini CLI, OpenCode (v1 & v2), Pi, Devin CLI, Kimi Code, Hermes Agent, and Muse.

# Keystone for OpenCode

Complete guide for using Keystone with [OpenCode.ai](https://opencode.ai).

## Installation

### OpenCode V1

```json
{
  "plugin": ["keystone@git+https://github.com/HarleySw/keystone.git"]
}
```

### OpenCode V2 (2.0.4 or later)

```json
{
  "plugins": ["keystone@git+https://github.com/HarleySw/keystone.git"]
}
```

Restart OpenCode and verify by asking: `"Tell me about your Keystone skills"`.
